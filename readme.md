# Expense traker

Es un proyecto tomado de la pagina de [Roadmap](https://roadmap.sh/projects/expense-tracker) para controlar y gestionar los gastos del usuario.

## Requerimientos
La aplicacion debera correr desde la linea de comandos cumpliendo las siguientes caracteristicas:
- [ ] Agregar un gasto con la descripcion y el monto.
- [ ] Actualizar un gasto.
- [ ] Eliminar un gasto.
- [ ] Listar todos los gastos.
- [ ] Listar el total de todos los gastos.
- [ ] Listar el total de gastos de un mes en especifico.
- [ ] Crear categorias de gastos.
- [ ] Listar gastos por categoria.

## Retos personales
- [ ] Usar typescript.
- [ ] Modularizar el proyecto.
- [ ] Archivo de configuracion para la aplicacion.
- [ ] Aprender como leer y guardar en CSV.
- [ ] Documentar codigo.
- [ ] Aprender como guardar las versiones del proyecto con ```tags``` de git.
